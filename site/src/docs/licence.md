# AscentUI Pro licence

This page says in plain words what you can and cannot do with AscentUI Pro items. It covers Pro only. The free items (the basic components, the theme and the agent kit) are under the MIT licence, which is more permissive.

"Pro items" means the Pro screens, data blocks and other Pro entries in the library, with their backend recipes: the contract, mock client, agent guide and checks.

## You can

- Use Pro items in as many projects as you like: personal, commercial and client projects.
- Change the code however you need.
- Ship Pro items inside a finished product, including one you sell.
- Keep Pro code in private repositories.
- Hand a finished project, with the Pro code inside it, to the client you built it for.
- Keep a private starter for your own team, if everyone who uses it holds a seat.
- Let your coding agent read and edit Pro code while working on your projects.

## You can't

- Publish Pro source on its own, in any form: files, a package, a registry, a download or a public repository.
- Sell it or give it away as a UI kit, template, component library, starter or registry, changed or unchanged.
- Build a product whose main purpose is to hand Pro items to its own users for them to build with, such as a page builder or a code generator.
- Share an access key or a seat with someone else, or post a key anywhere public.
- Remove the licence notice from the top of a Pro file.

## Common cases

| Case | Allowed? |
| --- | --- |
| A freelancer builds apps for five clients | Yes. One Individual licence covers the freelancer. Clients receive the finished apps |
| The client's own developers keep building on the Pro code afterwards | Yes, on that project. To use Pro items in other projects they need their own licence |
| A SaaS product whose screens are built from Pro items | Yes |
| An open-source app that includes Pro items | To be confirmed |
| A public template or boilerplate that includes Pro items | No |
| Putting an access key in a public repository or a shared file | No. Revoke it and create a new one |
| An agency of four people | A Team licence, or one Individual licence each |

## Seats

- **Individual** is one seat: one person.
- **Team** is up to 10 seats on one licence. Each person signs in with their own email and creates their own access key.
- A seat belongs to a person, not a machine. One person can use their key on all their own devices and in their own build pipelines.
- The buyer can move a seat when someone leaves the team. How often is to be confirmed.
- More than 10 people: to be confirmed.

## Access and updates

- You pay once. Access does not expire and there is no renewal.
- Your licence includes the Pro items added in later phases, at no extra cost.
- If a key is shared or published, it can be revoked. The licence stays in place and a new key can be created.
