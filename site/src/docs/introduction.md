# Introduction

AscentUI is a kit of business-ready React components and screens for people who build apps with coding agents.

Most business software, on a desk or a phone, is the same loop repeated: sign in, see a list, open a record, change it, get told it worked. AscentUI gives you and your agent that loop, done properly once, so the rest of the app can be built by repeating it.

## What is free and what is Pro

The rule is short: **every component is free. Screens that work are Pro.**

| | Free (MIT) | Pro (one payment) |
| --- | --- | --- |
| What it is | Every component, the theme, the agent kit, two showcase screens | Screens and data blocks, each with a backend recipe |
| Saves you | Minutes to hours | Days to weeks |

Two screens are free on purpose: **Sign in**, because every app needs one, and **Dashboard**, because it shows how the pieces fit together.

## What is ready today

AscentUI is in pre-release. Nothing is published yet.

- **Built:** the theme and all 31 core components: ten for actions and display, nine for forms, five for data and overlays (Toaster, Dialog + Drawer, Chart, Data Table and Month Grid), four for the app frame (App Shell, Command Menu, Stepper Form and Upload) and three for phones (Bottom Sheet, List Row and Pull to Refresh).
- **Planned:** everything else in the [library](#library). Each item there is marked built, part-built or planned.

These docs describe what exists and say "planned" where something does not exist yet.

## How it is delivered

- **Free items** install from an open registry with the shadcn CLI, or you can copy the files by hand.
- **Pro items** install from the same registry with a personal access key. You pay once, sign in with the same email, and create a key. This is planned for the Pro launch.
- **Agents** get an `llms.txt` file and, later, an MCP server, so they can read the docs before they write code.
